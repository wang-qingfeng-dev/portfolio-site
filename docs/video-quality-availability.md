# 视频清晰度发布说明

网站播放器的自动模式会优先选择最高可用清晰度；只要项目有 720p，页面就不会把 480p 作为公开选项。480p 仍作为网络或镜像失败时的内部回退源保留。

## 为什么有些 1080p 没有直接放入 GitHub

GitHub 普通仓库对单个文件有 100 MB 限制。为了避免把 1080p 原片偷偷替换成低码率版本，超过限制的文件暂时只保留在本地发布清单 `media/hd-1080p-manifest.json`。部署 Release、国内 OSS/COS 或 CDN 后，再把镜像根地址配置到 `mirror-config.js` 并开启 `allow1080`，页面即可在这些项目上显示 1080p。

当前已公开的 720p 文件均为完整时长的 H.264/AAC MP4；它们不是截取片段。页面在加载失败时会保留播放位置并回退到下一档可用源。
