# 视频清晰度发布说明

网站播放器的自动模式会优先选择最高可用清晰度；只要项目有 720p，页面就不会把 480p 作为公开选项。480p 仍作为网络或镜像失败时的内部回退源保留。

## 为什么有些 1080p 没有直接放入 GitHub

GitHub 普通仓库对单个文件有 100 MB 限制。超过限制的 1080p 文件暂时不显示为 GitHub Pages 的可选清晰度，避免点击后才静默回退。上传 Release、国内 OSS/COS 或 CDN 后，把同一路径放到镜像根目录并开启 `allow1080`（或把对应 `qualitySources["1080"]` 改为 Release URL），页面才会显示并播放 1080p。

当前已公开的 720p 文件均为完整时长的 H.264/AAC MP4；它们不是截取片段。页面在加载失败时会保留播放位置并回退到下一档可用源。
