# 视频清晰度发布说明

网站播放器的自动模式会优先选择最高可用清晰度；只要项目有 720p，页面就不会把 480p 作为公开选项。480p 仍作为网络或镜像失败时的内部回退源保留。

## 为什么有些 1080p 没有直接放入 GitHub

GitHub 普通仓库对单个文件有 100 MB 限制，因此四个大 1080p 文件放在公开 Release `media-1080p-v1`，代码已使用对应下载 URL。若 Release 在某个网络环境不可达，播放器会保留位置并回退到完整 720p；配置国内 OSS/COS 镜像后，可把这些 URL 替换为镜像地址。

当前已公开的 720p 文件均为完整时长的 H.264/AAC MP4；它们不是截取片段。页面在加载失败时会保留播放位置并回退到下一档可用源。
